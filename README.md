# Jack -- 3D Creator Portfolio

A dark-themed, high-performance 3D creator portfolio landing page built with **React**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, **Three.js**, and **Lucide React**.

## ✨ Features

- **Massive Hero Section**: Gradient typography (`.hero-heading`), mouse-following magnetic portrait effect, and interactive Three.js 3D geometric background with reactive lighting.
- **Scroll-Driven Horizontal Marquee**: Dual-row horizontal scroll gallery featuring 21 high-definition 3D design loops.
- **Interactive About Section**: Character-by-character scroll-linked text opacity animation surrounded by floating 3D assets.
- **Minimalist Services Directory**: 5 core 3D & design services with fluid typography and interactive hover states.
- **Sticky Stacking Projects Cards**: 3 dynamic project showcases with multi-column image layouts that stack and scale with scroll depth.
- **Interactive 3D Orbit Inspection**: Click "Live Project" on any card to orbit and inspect a real-time 3D geometry in a custom Three.js viewport.
- **Interactive Modals**:
  - Full project inspection drawer with deliverables and tech stack
  - Creative pricing tiers modal for the "Price" navigation action
  - Working Contact Modal with service/budget selectors, email copy, and celebratory confetti effects

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS + Google Fonts (Kanit)
- **Animation**: Framer Motion
- **3D & Shaders**: Three.js
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/sharmaaman99/jack-3d-portfolio.git

# Navigate to project directory
cd jack-3d-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
